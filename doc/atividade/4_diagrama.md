# Diagrama da Arquitetura

Crie um diagrama técnico contendo, no mínimo:

* `Usuário → Internet → DNS → Proxy Reverso → Frontend`
* `Frontend → DNS/API → Proxy Reverso → Backend → Banco de Dados`

O diagrama deverá mostrar:

* Domínio;
* DNS;
* Proxy reverso;
* Frontend;
* Redundância do Frontend;
* Backend;
* Banco de Dados;
* Firewall/controle de acesso;
* Portas;
* Protocolos;
* Fluxos permitidos;
* Fluxos bloqueados.

O diagrama deverá representar a arquitetura que foi realmente implementada.
