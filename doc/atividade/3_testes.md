# Testes

Após implementar a infraestrutura, realizem testes simples para comprovar o funcionamento e a segurança.

Demonstre:

1. O acesso ao Frontend utilizando o domínio;
2. O acesso ao Backend através do domínio/API;
3. O Frontend conseguindo acessar o Backend;
4. O Backend conseguindo acessar o Banco de Dados;
5. O acesso direto ao Backend sendo bloqueado;
6. O acesso direto ao Banco de Dados sendo bloqueado;
7. A aplicação continuando disponível quando um dos componentes redundantes do Frontend estiver indisponível.

Apresentem evidências dos testes, como screenshots ou logs.
