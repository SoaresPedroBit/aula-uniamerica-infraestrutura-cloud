
# Entrega

A entrega deverá conter apenas três itens:

### 1. Infraestrutura funcionando

A aplicação deverá estar funcionando no provedor de nuvem escolhido. O acesso deverá ser realizado utilizando o domínio/subdomínio configurado.

### 2. Diagrama

Um diagrama apresentando:

* Domínio;
* DNS;
* Proxy reverso;
* Front-end;
* Back-end;
* Banco de Dados;
* Redundância;
* Firewall/controle de acesso;
* Portas e protocolos;
* Fluxos permitidos e bloqueados.

### 3. Documentação curta

Um documento explicando:

* Quais serviços de nuvem foram utilizados;
* Por que foram escolhidos;
* Como a segurança foi implementada;
* Como funciona a redundância do Front-end;
* Como funciona o proxy reverso;
* Como o domínio foi configurado;
* Quais acessos foram permitidos e bloqueados.


### Regra Principal

Demonstrar que conseguem construir uma infraestrutura serverless simples, segura e redundante, utilizando domínio, DNS e proxy reverso, deixando claro no diagrama como cada camada é protegida e quais comunicações são permitidas ou bloqueadas.
